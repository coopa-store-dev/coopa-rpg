# 库巴大冒险

A game for the Coopa card, listed in the Coopa Store as game No. 2.

## Milestones

1. 升到 5 级 (2 stars)
2. 第 1 章通关 (5 stars)
3. 升到 10 级 (2 stars)
4. 第 2 章通关 (5 stars)

## Development

Same layout as the [Coopa game template](https://github.com/coopa-store-dev/coopa-game-template): with the Coopa SDK
installed, `coopa run` plays it in the browser and `coopa check --legacy` runs the same checks as the store.
This game predates the store's current rules and keeps its original save interface, so checks need `--legacy`
(the official check adds it automatically for repositories in this organization).
