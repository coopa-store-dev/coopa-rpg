# 库巴大冒险

库巴的大冒险。Coopa 卡上的游戏,在 Coopa Store 里上架(2 号)。

## 里程碑

1. 升到 5 级(2 颗星)
2. 第 1 章通关(5 颗星)
3. 升到 10 级(2 颗星)
4. 第 2 章通关(5 颗星)

## 开发

结构和 [Coopa 游戏模板](https://github.com/coopa-store-dev/coopa-game-template) 一样:装好 Coopa SDK 后,
`coopa run` 在浏览器里玩,`coopa check --legacy` 跑和商店一样的检查。
这款游戏写在商店的新规矩之前,用的是老的存档接口,所以检查要带 `--legacy`(官方检查对这个组织下的仓库自动带上)。
